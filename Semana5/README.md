# Semana 5: Proyectos pequeños y revisión final

En esta semana se realizaron las siguientes actividades:

1. **Creación de ejercicios de Java**: Se desarrollaron dos ejercicios prácticos en Java para reforzar los conceptos aprendidos en semanas anteriores.
2. **Organización de archivos**: Todos los archivos de práctica fueron organizados en la carpeta `Semana5` para mantener una estructura ordenada en el repositorio.
3. **Revisión de ejercicios anteriores**: Se revisaron y corrigieron los ejercicios de las semanas anteriores para asegurar su correcto funcionamiento.
4. **Preparación para la integración final**: Se prepararon todos los archivos para su integración en la Semana 6, donde se consolidarán todos los aprendizajes.
