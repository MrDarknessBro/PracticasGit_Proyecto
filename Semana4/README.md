# Semana 4: Colaboración y Pull Requests

En esta semana se realizaron las siguientes actividades:

1. Creación de una rama llamada `rama_semana4`.
2. Modificación de archivos de prueba dentro de la rama.
3. Creación de un pull request en GitHub para unir la rama con la rama principal (`main`).
4. Revisión y merge del pull request.
5. Resolución de conflictos si los hubo.
6. Subida de cambios al repositorio remoto.
